初めて使うとき・診断ファームの準備
  1. 右側に reel_right_diagnostics.uf2 を書き込みます。初回の書き込みにはUSBを使います。診断ファームのビルド成果物 ↗ の reel-rmk-firmware に含まれます。
  2. 右側のReeLをPCとBluetoothでペアリングします。Chrome / EdgeでこのURLを直接開き、「BLEで接続」でReeLを選ぶと、USBを外して計測・撮影できます。通常のキー入力も同じBLE接続で使います。
  3. 条件を記録し、静止 → 低速4方向 → 高速4方向の順に測ります。球、CPI、ケース位置を同時に変えず、各条件で同じ量を回します。
  4. ケースを調整した後に「角度・感度の較正」で補正します。測定後は通常の reel_right.uf2 に戻します。

USBで移動量だけ測る場合は「USBで接続」から右側のシリアルポートを選びます。実画像の撮影はBLE接続で使えます。古い診断ファームではBLE撮影が使えないため、最新のものを書き込んでください。

ブラウザ入力は書き換えなしで使えます。SQUAL・露光は取得できず、OSやファームの補正も含むPC側の出力を測ります。診断ファームは静止中も約4 msごとに読み出すため、通常版と消費電力・タイミングが異なります。

数値の読み方・調べた仕組み

SQUAL・露光は同じセンサー・同じ条件での相対比較に使います。全ての球に共通する合格値は設定していません。白・紫を同じ位置で比べ、次に同じ球でケース高さを変え、品質と軌跡が一緒に改善するか確認してください。

方向差は4方向の移動量の最小÷最大、高速/低速は同じ回転量に対する出力量の比で評価します。手の動き、CPI、球の回転軸も影響するため、値だけで原因を断定せず3回のばらつきも見ます。通信欠落・入力切断があった測定は比較に使いません。

自作キーボード向けのKeyball Link・Vial Webの実機設定の流れと、QMK Raw HIDの機器固有プロトコルを調査。ReeLの既存較正機能に、Web SerialとWeb Bluetoothによる診断を組み合わせました。実画像はPixArtのデータシートのフレーム取得手順と画素配置（17・33ページ）に従います。
